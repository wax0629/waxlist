# 地下精选模块（中文地下优质发行）

> 所属产品：Beat Hunter  
> 状态：后置认真建设（**不进入 Phase 1 Agent Beta**）  
> 形态：与「找伴奏」同站、**独立页面**，非 Agent 主对话技能  
> **视觉参考：** [design-refs-explore.md](./design-refs-explore.md)  
>  Collect UI：https://collectui.com/designs/ui-interaction-ui-design-inspiration/486780dd-83d9-4845-82d9-617599a4c2fa

---

## 1. 一句话

整理并展示**中文地下优质发行**，支持用户浏览与打分；需要时可通过「当参考找伴奏」跳入 Beat Hunter 主流程。

---

## 2. 为何独立成页（而不是塞进 Agent）

| 维度 | 找伴奏 `/chat` | 地下精选 `/explore` |
|------|----------------|---------------------|
| 对象 | 伴奏 / beat / instrumental | 已发行作品（歌 / EP / 专等） |
| 目标 | 分钟级 shortlist 可试唱 | 持续发现与口碑信号 |
| 交互 | 对话 + 工具调用 | 列表 / 详情 / 评分 |
| 数据 | 多源实时检索为主 | 策展库 + 评分 |
| 运营 | API 与适配器 | 选片、更新、防刷 |

混在同一对话会导致意图冲突与产品叙事稀释。  
**一站两页 = 不冗余**；强行一个 Agent 双任务 = 冗余且有害。

---

## 3. 目标用户

- 关注中文地下 / 非主流发行的听众  
- 歌手与创作者（与主产品用户重叠部分）  
- 希望有一条「从听到的专 → 找同气质伴奏」的路径  

---

## 4. 功能范围

### 4.1 规划中

- 策展发行列表（封面、标题、艺人、标签、外链）  
- 发行详情  
- 用户打分（量表形态实现时再定，如 1–5 或 1–10）  
- （可选）想听 / 收藏  
- **「用这首当参考找伴奏」** → `/chat?ref=...`  

### 4.2 分期建议

| 子阶段 | 内容 |
|--------|------|
| A | 只读精选列表 + 详情 + 外链（无账号） |
| B | 登录 + 打分 |
| C | 与 `/chat` 的 ref 深链打通；可选根据评分偏好辅助风格先验 |

### 4.3 不做（本模块内）

- 替代完整流媒体播放器  
- 未授权全曲托管/下载  
- 在 v0.1 对话 Agent 内做「荐专」（荐专仅后期附加；即便后期加上也不替代本页 dig 主体验）  
- 一上线就做复杂社交与关注关系  

---

## 5. 数据域（逻辑，独立于伴奏候选）

```text
Release {
  id
  title
  artists[]
  type          // single | ep | album | other
  tags[]        // 风格/场景等
  links[]       // 网易云 / B 站 / 乐队的天空等外链
  cover_url?
  description?
  curatorial_note?  // 为何收录
  status        // draft | published
  created_at / updated_at
}

Rating {
  id
  release_id
  user_id
  score
  created_at / updated_at
}
```

**禁止**与 `BeatCandidate` 混为同一张「万能音乐表」而不加类型区分。

---

## 6. 与找伴奏的弱连接

```text
用户在 /explore/releases/:id
  → CTA：用这首当参考找伴奏
  → /chat?ref=<release_id> 或 ?ref_url=<encoded>
  → chat 页预填参考上下文
  → parse_reference / 等价逻辑 → 伴奏 shortlist
```

可选增强（更晚）：用户历史高分标签 → 仅作为找伴奏的**弱风格先验**，不得替代用户当轮明确需求。

---

## 7. 内容与合规

- 以**元数据 + 外链**为主，不默认托管受版权保护的全曲文件  
- 策展需可说明来源；避免未授权搬运音频作为卖点  
- 打分区展示「主观评价，不代表平台立场」类说明（按需）  

---

## 8. 风险

| 风险 | 对策 |
|------|------|
| 与主线抢工期 | v0.1 不阻塞；入口可隐藏 |
| 冷启动无分可看 | 先只读精选 + 编辑推荐语 |
| 刷分 | 登录、频控、异常检测（B 阶段） |
| 选片主观争议 | 标明策展性质，小而美优于大而全 |
| 版权投诉 | 外链策略；投诉下架流程预留 |

---

## 9. 成功标准（二期）

- 精选质量达到「愿意反复打开」  
- 打分流程可完成且数据可展示  
- 至少一条完整演示：详情 → 当参考 → `/chat` 出伴奏短名单  

---

## 10. 决策摘要

| 项 | 结论 |
|----|------|
| 是否进 Beat Hunter | 是，**同站异页** |
| 是否进 v0.1 | **否**（必做仅 `/chat`） |
| 是否进 Agent tools | **v0.1 否**； dig 主体验在本页。Agent 荐专若做则为**后期附加**，跳转找伴奏仍由 `ref` / `parse_reference` 消费 |
| 与主产品关系 | 相邻模块 + 弱连接 |
