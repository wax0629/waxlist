# Beat Hunter 设计系统（色板 · 字体）

> 避免「默认紫灰 AI 风」。定位：**深夜棚里的伴奏工作台** —— 暖墨底 + 香槟金点缀 + 奶油字色。

## 字体

| 用途 | 字体 | 说明 |
|------|------|------|
| 品牌 / 大标题 | **Syne** | 略带展示感，拉丁标题有辨识度 |
| 正文 / 中文 UI | **Noto Sans SC** | 中文可读、现代无衬线 |
| 检索词 / 数据 | **JetBrains Mono** | 等宽，技术感 |

CSS 变量：`--font-display` · `--font-sans` · `--font-mono`

## 色板

| Token | 值 | 用途 |
|-------|-----|------|
| `--ink` | `#0c0b0a` | 页面底 |
| `--ink-elevated` | `#141210` | 面板 |
| `--cream` | `#f3eee6` | 主文字 |
| `--cream-muted` | `#9a9286` | 次级文字 |
| `--line` | `rgba(243,238,230,0.09)` | 描边 |
| `--gold` | `#d4a574` | 主强调（按钮、链接、高亮） |
| `--gold-soft` | `#e8c9a8` | 渐变高光 |
| `--ember` | `#c45c3e` | 次强调 / 热态（少用） |
| `--ok` | `#7dba8c` | 成功 |
| `--warn` | `#d4a017` | 降级 |
| `--danger` | `#d4736b` | 错误 |

**刻意不用：** 通用 violet-500 作为主品牌色。

## 气质关键词

温暖 · 克制 · 棚感 · 夜间 · 可触的金属质感（金）而非霓虹紫
