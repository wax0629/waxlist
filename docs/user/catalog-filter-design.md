# 优质发行分类筛选设计说明

> 状态：已实现；地区待补录，达到 90% 后自动开放前台筛选
>
> 最后更新：2026-08-06
> 目标页面：`/explore`

## 1. 背景

线上已收录百余张发行，全部已有 `released_at`；地区使用独立 `regions` 字段。
`tags` 继续承担轻量运营与风格标签，当前只开放规范化的 `UDG` 风格。

本期先解决两个稳定问题：

1. 用户可以按地区浏览。
2. 用户可以按发行年代浏览。

“风格”暂不定义完整分类树，只开放 `UDG` 单项，并复用现有 `tags` 存储。

## 2. 本期范围

### 做

- 地区筛选：国内、日本、欧美、其他。
- 年代筛选：2020 年代、2010 年代、2000 年代、2000 年以前。
- 桌面和移动端筛选交互。
- URL 可分享、可前进后退，并与搜索、浏览条件和排序共存。
- 后台地区补录与“待补充”队列。
- 荐专表单提供可选的多地区填写，空值继续进入“待补充”。
- 风格筛选中的 `UDG` 单项，以及荐专表单中的可选标签。

### 不做

- `UDG` 以外的风格内部分类和自动识别。
- 根据艺人名、语言或网易云数据自动猜地区。
- 国家级精细分类。
- 修改现有自由标签 `tags` 的含义。
- 分页、推荐算法和默认排序调整。

## 3. 分类原则

### 3.1 地区

地区按发行主要艺人的创作归属地判断，不按语言、网易云发行区或提交者所在地
判断。合作发行可以记录多个地区。

| key       | 前台名称 | 说明                               |
| --------- | -------- | ---------------------------------- |
| `cn`      | 国内     | 中国大陆、香港、澳门、台湾         |
| `jp`      | 日本     | 日本艺人或日本项目                 |
| `western` | 欧美     | 欧洲、北美及当前内容中同类英语地区 |
| `other`   | 其他     | 暂不值得单独拆分的地区             |
| `unknown` | 待补充   | 仅后台可见，不作为前台筛选项       |

`unknown` 是数据状态，不等同于 `other`。无法判断时保留 `unknown`，不要为了
清空队列强行归类。

### 3.2 发行时间

年代完全由已有 `released_at` 计算，不新增人工年代字段。

| key           | 前台名称    | 时间范围                 |
| ------------- | ----------- | ------------------------ |
| `2020s`       | 2020 年代   | 2020-01-01 至 2029-12-31 |
| `2010s`       | 2010 年代   | 2010-01-01 至 2019-12-31 |
| `2000s`       | 2000 年代   | 2000-01-01 至 2009-12-31 |
| `before-2000` | 2000 年以前 | 2000-01-01 之前          |

现有“发行时间”排序继续保留；筛选维度在界面上统一称为“年代”，避免排序与
筛选同名。

### 3.3 风格

本期只开放 `UDG`：

- 所有登录用户荐专时均可选择，选择后写入规范化标签 `UDG`。
- `/explore?filter=udg` 与侧栏“风格 → UDG”使用同一筛选结果。
- 大小写不同或重复的输入统一收敛为一个 `UDG`。
- 暂不新增 `style`、`genre` 或 `style_groups` 字段。
- 现有站主上传或站主推荐的已上架专辑，通过 `node scripts/tag-owner-releases-udg.mjs` 一次性补标；脚本可重复执行。

### 3.4 上传时的地区填写与自动化边界

荐专表单在网易云信息解析后提供“地区（可多选，可留空）”。用户可以补充自己确定
的地区，但不因空值阻止提交；重复推荐已有专辑时不覆盖管理员已经确认的地区。

当前网易云解析接口能稳定提供标题、艺人、封面、公司和发行日期，缺少可依赖的地区
字段，因此本期不根据艺人名、语言或风格猜测地区。后续若接入可信的艺人资料来源，
只显示“地区建议”，仍由用户或 owner/admin 确认后才写入 `regions`。

## 4. 信息架构

现有“浏览”条件继续表示用户与运营状态：

- 全部
- UDG 专区（带 `UDG` 标签并已上架）
- 我的红心
- 站主爱听
- 友情

新增“分类筛选”表示发行本身的属性：

- 地区
- 年代
- 风格（当前仅 UDG）

“浏览”和“分类筛选”不可混为同一组选项。用户可以组合使用，例如：

```text
我的红心 AND 国内 AND 2020 年代
```

## 5. 桌面端设计

分类筛选放在 `/explore` 左侧栏，位于“浏览”下方、“排序”上方。

```text
浏览
  全部
  UDG 专区
  我的红心
  站主爱听
  友情

筛选
  [地区  2]
    全部地区
    国内
    日本
    欧美
    其他

  [年代]
    全部年代
    2020 年代
    2010 年代
    2000 年代
    2000 年以前

  风格
    UDG

排序
  推荐先后
  发行时间
```

交互规则：

- 地区和年代按钮点击后在侧栏内展开，不使用会被容器裁切的浮层菜单。
- 筛选组在侧栏内展开，不遮挡专辑列表。
- 地区允许多选；地区内部为 OR。
- 年代单选。
- 不同维度之间为 AND。
- 每次选择立即更新列表和 URL。
- 已选数量显示在按钮右侧；无选择时不显示数字。

## 6. 移动端设计

移动端不横向堆叠地区、年代和风格三排选项。

- 在列表顶部、现有排序旁增加一个带筛选图标的“筛选”按钮。
- 点击后打开底部筛选面板。
- 面板包含“地区”“年代”“风格”三个分区。
- 风格分区显示可选择的 `UDG`，其他细分类暂不展示。
- 底部固定“查看 N 张”主按钮和“重置”命令。
- 面板关闭后，列表上方显示可横向滚动的已选条件，例如“国内 ×”“2020年代 ×”。

筛选面板内先暂存选择，点击“查看 N 张”后统一写入 URL，避免每点一次都关闭
面板或触发页面跳动。

## 7. URL 与组合规则

建议参数：

```text
/explore?region=cn,jp&period=2020s&filter=heart&sort=released&q=xxx
```

规则：

- `region`：逗号分隔，允许多个合法 key。
- `period`：单个合法 key。
- 未选择地区或年代时省略对应参数，不写 `all`。
- `UDG` 使用既有 `filter=udg` 参数；浏览区的 UDG 专区与风格筛选互为同一状态。
- 修改分类时必须保留 `filter`、`sort` 和 `q`。
- 非法值忽略并回退为全部，不返回错误页。
- 空结果页面提供“清除分类筛选”，不清除搜索词和排序。

## 8. 数据设计

`Release` 新增：

```prisma
regions String[] @default([])
```

约定：

- 空数组在业务上等同 `unknown`。
- API 输出使用 `regions: string[]`。
- 创建普通用户荐专时不强制选择地区，默认进入待补充队列。
- owner/admin 可补录和修改地区。
- `released_at` 继续作为年代唯一来源。
- 当前不新增独立风格字段，`UDG` 规范存于 `tags`。

第一版数据量只有百级，继续在服务端查询后筛选；地区解析、年代计算、组合筛选
和统计统一放在 `src/lib/releases/catalog.ts`，页面和后台不复制判断逻辑。

## 9. 后台补录

增加“分类维护”入口，owner 和 admin 可访问。

列表字段：

- 封面
- 标题 / 艺人
- 发行日期
- 当前地区
- 保存状态

默认只显示“待补充”，支持：

- 按地区快速选择。
- 多选发行后批量设置地区。
- 保存后自动移到下一条。
- 切换查看全部。

前台地区筛选在至少 90% 的已发布发行完成补录后再开放；年代筛选不依赖补录，
可以先完成。

## 10. 状态与空态

| 状态     | 表现                                      |
| -------- | ----------------------------------------- |
| 正常     | 显示筛选后的专辑网格                      |
| 载入     | 保持当前网格骨架，不显示全屏 spinner      |
| 空结果   | “没有符合这些条件的专辑” + “清除分类筛选” |
| 地区缺失 | 前台仍出现在“全部”；后台进入“待补充”      |
| 非法 URL | 忽略非法参数，其他合法参数继续生效        |
| UDG 风格 | 只显示带规范化 `UDG` 标签的已上架专辑     |

- [x] 地区支持国内、日本、欧美、其他，多选结果正确。
- [x] 年代筛选由 `released_at` 自动计算。
- [x] 地区内部 OR，地区与年代之间 AND。
- [x] 搜索、浏览、分类、排序可以组合使用。
- [x] URL 可复制分享，前进/后退状态正确。
- [x] 桌面筛选在左侧栏内展开。
- [x] 移动端通过单一筛选入口完成操作，不发生横向溢出。
- [x] 风格按钮提供 UDG 选项，并与 UDG 专区共用筛选结果。
- [x] `unknown` 不出现在前台选项中。
- [x] 空结果只清除分类，不误清搜索词和排序。
- [x] 后台可以筛出并批量处理待补充地区的发行。

地区前台入口受覆盖率门槛保护。刚部署时现有数据均为空数组，管理或站主需要先到
`/admin/categories` 补录；达到 90% 后无需再次改代码或发版。
