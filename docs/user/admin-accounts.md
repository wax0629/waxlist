# 管理账号怎么分发

角色三级：

| 角色 | 能做什么 | 谁能指定 |
|------|----------|----------|
| **站主** `owner` | 全部：内容管理、分类维护、站主上架、友情标签、**分配/取消管理** | 见下方「站主怎么来」 |
| **管理** `admin` | 后台、**内容管理（事后下架）**、分类维护、荐专上架 | 仅站主在后台「账号与角色」页操作 |
| **用户** `user` | 查看评分评论、荐专**默认上架**、红心；发布评分/评论需单独开放互动内测 | 默认注册 |

后台入口：`/admin`（员工可见侧栏盾牌图标）。

## 开放评分与评论内测

站主进入 `/admin/users`，在用户所在行点击“互动内测”的“未开放”按钮即可开启；再次点击可关闭。站主账号始终开放，无需设置。

- 该开关不改变账号角色，不会授予后台权限。
- 关闭后仍可查看均分和已有评论，但不能发布新的评分/评论；历史数据不会删除。
- 权限通过登录会话缓存，最迟 15 分钟自动同步；用户重新登录可立即生效。

## 站主怎么来

任选其一（可并存）：

1. **库里第一个注册用户**自动为站主（空库时）  
2. 环境变量 **`OWNER_EMAILS`**（逗号分隔邮箱）：登录/注册时会同步为站主  
   例：`OWNER_EMAILS=you@example.com,ops@example.com`  
3. 数据库里手动改 `users.role = 'owner'`（慎用）

生产改 `OWNER_EMAILS` 后需重启进程（`pm2 restart` / `deploy-prod`），下次登录会生效。

---

## 推荐：给朋友开「管理」

1. 对方自己在 https://waxlist.cn 用**真实邮箱注册**并设密码  
2. 站主登录 → 侧栏盾牌 → **后台** → **账号与角色**  
3. 找到该用户 → **设为管理**  
4. 对方重新登录（或刷新会话）后即可进内容管理与分类维护

**不要**把站主密码直接借给别人。管理权限足够浏览近期荐专和下架问题内容。

---

## 不推荐的做法

- 把站主账号密码群发  
- 给不认识的人开管理  
- 用一个共享「管理号」多人登录（难追责、难踢人）

---

## 取消管理

站主在 **账号与角色** 点 **降为用户** 即可。  
对方会失去内容管理与后台入口；其历史操作仍留在数据里。

---

## 一期 / 二期范围

| 期 | 内容 | 路径 |
|----|------|------|
| **一期** | 后台概览、遗留待审数字、跳转内容管理 | `/admin` |
| **二期** | 账号列表、升/降管理 | `/admin/users` |
| 已有 | 内容管理：近期荐专、事后下架、遗留待审处理 | `/moderation` |
| 已有 | 分类维护：地区补录、批量设置与覆盖率 | `/admin/categories` |
| 站主/管理发专 | 用前台「推荐专辑」即可直接上架（员工免审） | `/explore/submit` |

遗留待审角标：侧栏盾牌、用户菜单的内容管理入口旁会显示数量；新提交不会增加待审数。
