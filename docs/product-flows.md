## 1. 产品一句话

**帮歌手用自然语言/参考曲，快速拿到可试听伴奏短名单；同站可选地下发行精选。**

## 2. 六大功能块（整站）

```text
┌─────────────────────────────────────────────────────────────┐
│                     Beat Hunter 完整产品                      │
├──────────────┬──────────────┬──────────────┬────────────────┤
│  ① 找伴奏     │  ② 检索智能   │  ③ 结果资产   │  ④ 地下精选    │
│  对话体验     │  理解→搜→排   │  收藏/历史    │  策展+打分     │
│  /chat        │  Agent+多源   │  账号侧       │  /explore      │
├──────────────┴──────────────┴──────────────┴────────────────┤
│  ⑤ 账号与信任          │  ⑥ 平台工程（部署/数据/质量/合规）   │
└────────────────────────┴────────────────────────────────────┘
```

| 块 | 是什么 | 用户感知 | 现状粗分 |
|----|--------|----------|----------|
| **① 找伴奏体验** | 对话 UI、会话、加载/错误、新会话 | 「像一个能聊的产品」 | 能用，未成品质感 |
| **② 检索智能** | Intent、query 策略、多源召回、过滤、制作人先验、精排 | 「比自己搜 YouTube 懂行」 | **主竞争力，部分完成** |
| **③ 结果与资产** | shortlist、理由、收藏、历史、分享 | 「结果能留下、能回去」 | 只有当轮卡片 |
| **④ 地下精选** | 列表/详情/打分/当参考跳转 | 「同站还能挖专」 | 仅占位 |
| **⑤ 账号与信任** | 登录、游客策略、关于/合规 | 「正式、可托付」 | 几乎没有 |
| **⑥ 平台工程** | 部署、DB、监控、限流、测试 | 「能稳定给别人用」 | 本机开发态 |

## 3. 四条主流程（用户怎么走）

### 流程 F1 — 描述找伴奏（主路径）

```text
打开 /chat
  → 自然语言描述（或点建议 chip）
  → 系统：理解 Intent + 展示「我的理解」
  → 多路伴奏域检索 + 过滤排序
  → 展示检索词（可折叠）+ 3～5 卡片
  → 点开源站试听
  → （可选）refine「再快一点」→ 更新理解再搜
```

| 涉及块 | ① 体验 · ② 智能 · ③ 结果（当轮） |
| 现状 | **可跑通**；准度/噪音/UI 需加强 |
| 完整产品 | 准、稳、可解释、可 refine、移动端顺 |

---

### 流程 F2 — 参考曲找伴奏

```text
粘贴 YouTube 链接 或 /chat?ref_url=…
  → 解析参考（标题/hints）
  → 并入 Intent + 策略检索
  → shortlist（理由提到参考）
  → refine / 打开源站
```

| 涉及块 | ① · ② · ③ |
| 现状 | **可跑通**（YT）；非 YT 弱 |
| 完整产品 | 解析稳、与 explore 深链打通 |

---

### 流程 F3 — 留下与回来（资产闭环）

```text
找到喜欢的伴奏
  → 收藏 / 加入 shortlist
  →（登录则）云端保存
  → 下次从历史会话或收藏库进入
  → 继续 refine 或换方向找
```

| 涉及块 | ③ 结果资产 · ⑤ 账号 · ⑥ 持久化 |
| 现状 | **几乎没有**（刷新靠内存会话） |
| 完整产品 | 游客可搜；登录可存；历史可回 |

---

### 流程 F4 — 地下精选 → 找伴奏（弱连接）

```text
/explore 浏览策展发行
  → 详情 + 外链听
  →（可选）打分
  →「用这首当参考找伴奏」
  → /chat?ref=… → 进入 F2
```

| 涉及块 | ④ 地下精选 · ①② · ⑤（打分） |
| 现状 | **未做**（导航占位） |
| 完整产品 | 精选质量 + 弱连接可演示 |

## 4. 大块与分期（完整产品口径）

| 大块 | Phase 1 Beta（先做成「能给人用」） | Phase 2（主产品做透） | Phase 3（宇宙补全） |
|------|-----------------------------------|----------------------|---------------------|
| ① 体验 | UI 成品质感、错误重试、移动端 | 流式、多会话切换 | — |
| ② 智能 | 词典/过滤、制作人先验、LLM 精排、eval | 多源、缓存、策略运营 | — |
| ③ 资产 | 会话 **持久化** | 收藏、分享、历史列表 | — |
| ④ 精选 | 可不做或极简占位页 | — | 列表+详情+打分+弱连接 |
| ⑤ 账号 | 关于/合规文案；游客可搜 | 登录 + 云同步资产 | 打分身份 |
| ⑥ 工程 | **部署 + DB + 基础日志/限流** | CI/监控加强 | 运营后台 |

## 5. 依赖关系（为什么这个顺序）

```text
② 检索智能 ──┐
① 体验打磨 ──┼→ 公开 Beta 可用（Phase 1）
⑥ 部署+DB  ──┘
         │
         ▼
⑤ 账号 + ③ 收藏历史（Phase 2）
         │
         ▼
④ 地下精选弱连接（Phase 3）
```

没有 ②+①+⑥，谈不上完整产品对外；  
没有 ③+⑤，只有「用一次就走」；  
没有 ④，文档里的一站两页不完整，但**可以后做**。
