# Phase 1 — Agent / 找伴奏 Beta 规格（草稿可开工）

> 状态：**范围已锁定，可开工**  
> 原则：**只做 Agent 找伴奏**；地下精选后置认真做，本阶段不开发 explore。  
> 依据：[product-flows.md](./product-flows.md)、[product-maturity.md](./product-maturity.md)、v0.1/v0.2 已交付地基  

---

## 1. 一句话目标

交付 **可公开访问的找伴奏 Beta**：检索比裸搜 YouTube 更懂行、体验像样、会话不丢、能稳定演示。

---

## 2. 范围

### 2.1 做（Phase 1）

| 包 | 内容 |
|----|------|
| **检索智能** | 词典扩展、噪音过滤加强、风格→制作人软先验、LLM 精排 reason、20 条 eval |
| **/chat 体验** | UI 成品质感（Suno 向）、空/错/降级/重试、移动端可用 |
| **会话** | DB 持久化（重启/刷新不丢） |
| **上线** | 生产部署 + 环境变量 |
| **工程底线** | API 限流、关键日志（intent/queries/耗时/错误） |
| **信任** | 简短关于 + 试听/商用说明 + Beta 标识 |

### 2.2 明确不做（本阶段）

- `/explore` 列表、详情、打分、运营录入（**保留产品规划，后置**）  
- 登录/注册、云同步收藏库  
- 多源 BeatStars/B 站真接入  
- 流式 token、多会话列表  
- 荐专、编曲、下载

## 3. 用户故事（Beta 验收）

| ID | 故事 | 验收 |
|----|------|------|
| B1 | 描述找伴奏 | 理解 + 检索词 + ≤5 真链卡片；非默认乱 rnb |
| B2 | 参考链接 | YT 解析进策略；理由/理解有参考信号 |
| B3 | Refine | 约束更新，结果/query 有变化 |
| B4 | UDG 等非 R&B | 风格不被粘成 rnb |
| B5 | 失败可恢复 | 降级说明 + 可再试 |
| B6 | 刷新不丢会话 | DB 持久化后成立 |
| B7 | 公开 URL | 他人无需 clone 即可用（自备配额） |
| B8 | 移动端 | 手机浏览器可完成 B1 |
